# User Workflow

1. Load song, stem, or later video.
2. Establish BPM/beat grid automatically or manually.
3. Split the song or attach supplied stems.
4. Work with each source/stem as a mixer channel.
5. Slice, loop and arrange clips on the beat grid.
6. Select a stem and choose **Rebuild Instrument**.
7. Compare original and rebuilt versions.
8. Keep the preferred version and continue mixing.
9. Send a stem/loop/clip to LibertasDJ Deck A or B through the shared contract.
10. Export stems or a finished master.

Advanced model names, worker routing and performance maps remain available but are not the primary normie workflow.
