# Fidelis Vision

Fidelis is becoming a reconstructed mixing deck: import a song or video, split or attach stems, manipulate them as mixer channels and clips, rebuild weak/synthetic instruments while preserving performance, and hand the same musical objects to LibertasDJ.

The frozen Fidelis reconstruction core remains intact. New work wraps that core with mixer, timeline, media, DSP, model and interop layers instead of replacing it.

User-facing path:

`LOAD → SPLIT/ATTACH STEMS → MIX → LOOP/EDIT → REBUILD INSTRUMENT → A/B → LIBERTASDJ → EXPORT`
